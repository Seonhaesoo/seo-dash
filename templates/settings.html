키 만드는 순서 (한 번만)
  1. console.cloud.google.com 접속 → 위쪽 프로젝트 선택 → 새 프로젝트 (이름 아무거나, 예: seo-dash)
  2. 왼쪽 메뉴 API 및 서비스 → 라이브러리에서 세 개를 검색해 각각 사용: Google Search Console API, Google Analytics Data API, Google Analytics Admin API
  3. IAM 및 관리자 → 서비스 계정 → 서비스 계정 만들기 (이름 seo-dash) → 만들기 → 역할은 건너뛰고 완료
  4. 만든 계정 클릭 → 키 탭 → 키 추가 → 새 키 만들기 → JSON → 파일이 내려받아짐 (이 파일이 비밀번호입니다. 다른 곳에 올리지 마세요)
  5. 그 파일을 위 "키 저장"으로 올리기 → 화면에 나오는 이메일(…@…iam.gserviceaccount.com)을 복사
  6. 서치콘솔 (search.google.com/search-console) → 속성마다 왼쪽 아래 설정 → 사용자 및 권한 → 사용자 추가 → 이메일 붙여넣기, 권한 전체
  7. GA4 (analytics.google.com) → 왼쪽 아래 관리 → 속성 액세스 관리 → + → 사용자 추가 → 이메일, 역할 뷰어 (속성마다)
  8. 성적표로 돌아가 지금 동기화
